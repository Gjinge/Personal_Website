Overview

A collection of introductory Unity scripting exercises. The main cube-management script creates primitives, stores them in a List, shrinks them over time, and removes them after they reach a size threshold.

Implementation highlights

  • Object creation. The cube manager creates colored cube primitives at random positions inside a unit sphere.
  • Safe collection updates. A separate removal list collects expired objects before removing and destroying them.
  • List fundamentals. ListEx.cs demonstrates adding strings, indexing a list, iterating through it, and reporting its count.

            }
